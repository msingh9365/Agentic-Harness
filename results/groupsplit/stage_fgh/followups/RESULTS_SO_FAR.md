## Night-run update 2 (2026-11-22, 20:50 UTC): the two test-time baselines (Part 3) are done
Final M1 and M3 (corrected tokenizer), no retraining, prepend padding, thresholds recalibrated on each variant's own clean April scores. **Dedupe of exact repeats changes nothing** (clean pAUC@1e-2 -0.23 / +0.06 points, not resolved; detection under random 100 prepend 5.6 / 6.5%, same as without); **dedupe by API name hurts** the clean results (-22.9 / -15.1 points, resolved) and does not help under attack. **Multi-window max (every 512-token window, maximum logit) recovers detection under long prepend padding** (M3 random 100 prepend 6.5 → 68.3%; M3 LightGBM 50 prepend 35.1 → 58.0%; M1 random 50 prepend 7.4 → 29.5%) **but costs clean performance** (pAUC@1e-2 -21.1 for M1 and -11.0 for M3, resolved) and detection at the 1% threshold unedited (M3 79.0 → 71.8, M1 79.1 → 61.0). Only prepend, no white-box, and an attacker who knows the rule was not tried. NOTES 27.2; files `part3/`.
