# What the attention pooling looks at (round 4)

20 random April malware reports, each prepended with 20 random calls of the EVAL pool (the "prepend 20" edit of the padding test; in memory only). Attention weight = weight of a token in the pooled vector (they sum to 1 over the real tokens). "Share on the prepended tokens": attention weight that falls on the first n tokens after the edit, n = growth of the token sequence (at most 512); "share with mean pooling": n / number of real tokens.
